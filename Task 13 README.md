# Prime Number Analyzer

## 1. Project Overview

The Prime Number Analyzer is a Python application that checks whether a given integer is a prime number. It also generates a list of prime numbers within a user-defined range.

The project demonstrates mathematical logic, functions, loops, conditional statements, and basic algorithm optimisation.

## 2. Objectives

* Develop a prime number checking program.
* Understand the mathematical definition of prime numbers.
* Generate prime numbers within a specified range.
* Practise functions and loops.
* Implement efficient divisor checking.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Checks whether an individual integer is prime.
* Generates prime numbers within a specified range.
* Accepts starting and ending values from the user.
* Automatically handles reversed range endpoints.
* Uses divisor checks up to the square root of the number.

## 7. Usage

1. Run the Python program.
2. Enter an integer to check whether it is prime.
3. Enter the starting value of the range.
4. Enter the ending value of the range.
5. View the prime numbers identified by the program.

## 8. Error Handling

The program handles invalid integer input through its input-validation logic. Numbers below two are correctly identified as non-prime numbers.

## 9. Learning Outcomes

This project develops practical experience with functions, loops, modulo arithmetic, range processing, list comprehensions, conditional statements, and basic algorithm optimisation.

## 10. Conclusion

The Prime Number Analyzer demonstrates how Python can be used to solve mathematical problems through programming. It strengthens understanding of prime numbers, efficient algorithms, and logical problem-solving.
