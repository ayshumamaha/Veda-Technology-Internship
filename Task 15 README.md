# Shopping Bill Generator

## 1. Project Overview

The Shopping Bill Generator is a Python application that calculates the total cost of purchased items. It accepts product names, quantities, and unit prices, then calculates the subtotal, discount, tax, and final payable amount.

The project demonstrates arithmetic operations, lists, dictionaries, functions, and input validation.

## 2. Objectives

* Develop a shopping bill generation program.
* Calculate item-wise costs and the subtotal.
* Apply discounts and tax percentages.
* Practise functions and data structures.
* Validate product details and numerical inputs.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Accepts multiple product entries.
* Collects product names, quantities, and prices.
* Calculates individual item costs.
* Calculates the subtotal.
* Applies percentage-based discounts.
* Calculates tax on the discounted amount.
* Displays the final payable bill.
* Uses Indian rupee formatting.

## 6. Installation and Setup

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder in your code editor.
4. Open the terminal.
5. Execute the program.

```bash
python "Task 14.py"
```

## 7. Usage

1. Run the Python program.
2. Enter the product name.
3. Enter the quantity and price per item.
4. Repeat for additional products.
5. Enter `done` when all products have been added.
6. Provide the requested discount and tax percentages.
7. Review the generated shopping bill.

## 8. Error Handling

The program checks for empty product names, invalid numerical values, non-positive quantities, and negative prices before processing the bill.

## 9. Learning Outcomes

This project provides practical experience with lists, dictionaries, functions, arithmetic operations, loops, input validation, and formatted billing output.

## 10. Conclusion

The Shopping Bill Generator demonstrates how Python can be used to automate basic billing calculations. It strengthens understanding of data handling, mathematical operations, and real-world application development.
