# Temperature Converter Using Python

## 1. Project Overview

The Temperature Converter is a menu-driven Python application that converts temperatures between Celsius, Fahrenheit, and Kelvin. It provides different conversion options and uses separate functions for each conversion formula.

The project demonstrates arithmetic operations, functions, dictionaries, loops, and conditional statements.

## 2. Objectives

* Develop a temperature conversion application.
* Understand temperature conversion formulas.
* Create reusable conversion functions.
* Practise dictionary-based menu selection.
* Perform mathematical calculations using Python.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Converts Celsius to Fahrenheit.
* Converts Celsius to Kelvin.
* Converts Fahrenheit to Celsius.
* Converts Fahrenheit to Kelvin.
* Converts Kelvin to Celsius.
* Converts Kelvin to Fahrenheit.
* Provides a menu-driven interface.
* Allows multiple conversions before exiting.

## 6. Installation and Setup

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder.
4. Open a terminal in the project directory.
5. Run the program.

```bash
python "Task 13.py"
```

## 7. Usage

1. Run the Python program.
2. Select the required conversion option.
3. Enter the temperature value.
4. View the converted temperature.
5. Repeat the process for additional conversions.
6. Select the exit option to close the program.

## 8. Error Handling

The program provides menu options for selecting conversions and accepts numerical temperature values. Users should enter valid numeric input and ensure Kelvin temperatures are not below absolute zero.

## 9. Learning Outcomes

This project provides practical experience with mathematical formulas, functions, dictionaries, loops, conditional statements, and formatted output.

## 10. Conclusion

The Temperature Converter demonstrates how Python can be used to build a practical mathematical utility. It strengthens understanding of functions, arithmetic operations, and menu-driven application development.
