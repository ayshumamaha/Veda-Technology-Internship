# Contact Book Using Python Dictionaries

## 1. Project Overview

The Contact Book is a menu-driven Python application that stores contact details using dictionaries. Each phone number acts as a unique key, while the associated value contains the contact's name and email address.

The application allows users to add, search, update, delete, and view contact information.

## 2. Objectives

* Understand dictionary-based key-value storage.
* Implement CRUD operations for contact records.
* Practise functions and menu-driven programming.
* Validate contact information.
* Handle duplicate and missing contacts.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Includes two sample contacts.
* Adds new contacts.
* Prevents duplicate phone numbers.
* Searches contacts using phone numbers.
* Updates contact names and email addresses.
* Deletes contacts after confirmation.
* Displays contacts in phone-number order.

## 6. Installation and Setup

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder in your code editor.
4. Open a terminal.
5. Run the program.

```bash
python "Task 9.py"
```

## 7. Usage

1. Run the Python program.
2. Select an option from the Contact Book menu.
3. Enter the requested phone number and contact details.
4. Use the search option to find a contact.
5. Use the update or delete options to manage records.
6. Select View All Contacts to display saved contacts.
7. Choose Exit to close the program.

## 8. Error Handling

The program handles empty names and phone numbers, duplicate phone numbers, missing contacts, invalid menu selections, and keyboard interruption.

Contact information is stored in memory and is not saved permanently between executions.

## 9. Learning Outcomes

This project provides practical experience with dictionaries, nested data structures, CRUD operations, functions, sorting, conditional statements, and exception handling.

## 10. Conclusion

The Contact Book demonstrates how Python dictionaries can be used to build a simple contact-management application. It strengthens understanding of key-value storage and basic data-management operations.
