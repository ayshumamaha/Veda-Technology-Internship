# Palindrome Checker

## 1. Project Overview

The Palindrome Checker is a Python application that determines whether a word or sentence reads the same forwards and backwards. It converts the input into lowercase and removes non-alphanumeric characters before performing the comparison.

The project demonstrates string normalisation, slicing, functions, and conditional statements.

## 2. Objectives

* Develop a palindrome-checking program using Python.
* Understand string manipulation and normalisation.
* Practise string slicing and comparison.
* Create reusable functions.
* Validate user input.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Accepts words and sentences.
* Ignores uppercase and lowercase differences.
* Ignores spaces and punctuation.
* Removes non-alphanumeric characters before comparison.
* Identifies whether the input is a palindrome.
* Includes example palindrome checks.

## 7. Usage

1. Run the Python program.
2. Enter a word or sentence.
3. The program normalises the text.
4. View whether the entered text is a palindrome.
5. Review the example checks displayed by the program.

## 8. Error Handling

The program checks for empty or whitespace-only input before performing the comparison and displays an appropriate message.

## 9. Learning Outcomes

This project provides practical experience with strings, isalnum(), lower(), slicing, functions, list-style comprehensions, and conditional statements.

## 10. Conclusion

The Palindrome Checker demonstrates how Python string operations can be used to solve text-based problems. It strengthens understanding of string comparison, data normalisation, and reusable functions.
