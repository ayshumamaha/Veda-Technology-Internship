# Basic Unit Testing Project Using Python

## 1. Project Overview

The Basic Unit Testing Project is a Python application developed as part of the Python Programming Internship at Veda Technology. It implements a simple calculator with basic arithmetic functions and tests their functionality using Python.

The project includes addition, subtraction, multiplication, and division operations. It uses simple test cases to verify the correctness of each function, including handling invalid operations such as division by zero.

## 2. Objectives

* Develop a simple Python project with multiple functions.
* Understand the fundamentals of unit testing.
* Test the correctness of arithmetic operations.
* Practise using assert statements for testing.
* Test both valid and invalid inputs.
* Identify errors and verify expected program behaviour.

## 3. Technologies Used

* Python 3
* Python assert statements
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Performs addition of two numbers.
* Performs subtraction of two numbers.
* Performs multiplication of two numbers.
* Performs division of two numbers.
* Handles division-by-zero errors.
* Includes 10 independent test cases.
* Displays PASS messages for successful tests.
* Displays a final test completion message.

## 6. Installation and Setup

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your preferred code editor.
4. Open a terminal in the project directory.
5. Run the program using the command below.

```bash
python task32_unit_testing.py
```

On some systems, you may need to use `python3 task32_unit_testing.py` instead.

No external Python libraries are required.

## 7. Usage

1. Run the Python program.
2. The calculator functions are defined for basic arithmetic operations.
3. The program executes the predefined test cases.
4. Each test checks whether the actual result matches the expected result.
5. The program displays PASS messages for successful tests.
6. A final message confirms that all 10 tests have been completed successfully.

## 8. Testing and Error Handling

The project contains 10 test cases covering different arithmetic operations and input conditions.

The test cases include:

* **Addition:** Checks addition of positive and negative numbers.
* **Subtraction:** Verifies normal subtraction and negative results.
* **Multiplication:** Tests multiplication and multiplication by zero.
* **Division:** Checks normal division and decimal results.
* **Decimal Addition:** Verifies addition using decimal numbers.
* **Division by Zero:** Checks whether the program correctly raises and handles a ValueError.

The program uses assert statements to verify expected results and try-except handling to test division-by-zero errors.

## 9. Learning Outcomes

This project provides practical experience with Python functions, arithmetic operations, assert statements, exception handling, and basic software testing. It also introduces the importance of testing individual functions to identify errors and ensure that a program behaves as expected.

## 10. Conclusion

The Basic Unit Testing Project demonstrates how Python can be used to develop and test simple applications. By implementing 10 test cases, the project provides a foundation for understanding automated testing, error handling, and software quality assurance.
