# Exception Handling Demonstration

## 1. Project Overview

The Exception Handling Demonstration is a Python program that explains how runtime errors can be handled using exception-handling mechanisms. It includes examples involving division, list indexing, and dictionary key lookup.

The project demonstrates try, except, else, and finally blocks and explains how Python programs can respond to common errors.

## 2. Objectives

* Understand exception handling in Python.
* Practise try and except blocks.
* Handle division-by-zero errors.
* Handle invalid list indexing.
* Handle missing dictionary keys.
* Understand the use of finally blocks.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Performs safe division of two numbers.
* Handles division-by-zero errors.
* Demonstrates valid and invalid list index access.
* Demonstrates dictionary key lookup.
* Handles missing dictionary keys.
* Displays appropriate error messages.
* Uses a finally block to display completion information.

## 8. Error Handling

The program demonstrates handling of ValueError, ZeroDivisionError, IndexError, and KeyError. It uses exception-handling blocks to prevent common errors from terminating the examples unexpectedly.

## 9. Learning Outcomes

This project provides practical experience with try, except, else, finally, exception types, error handling, and writing reliable Python programs.

## 10. Conclusion

The Exception Handling Demonstration highlights the importance of handling runtime errors in Python applications. It strengthens understanding of exception-handling techniques and improves the ability to develop robust programs.
