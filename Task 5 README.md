# Multiplication Table Generator

## Description
A simple Python program that generates the multiplication table of a number up to a specified limit.

## Features
- Accepts a number from the user.
- Allows the user to specify the limit.
- Displays the multiplication table in a clear format.

## Requirements
- Python 3

## How to Run
1. Download the Python file.
2. Open a terminal in the file's folder.
3. Run the command:

```bash
python multiplication_table.py
```

4. Enter the number and limit when prompted.
