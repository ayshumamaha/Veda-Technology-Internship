# Simple To-Do List Using Python

## 1. Project Overview

The Simple To-Do List is a menu-driven Python application developed as part of the Python Programming Internship at Veda Technology. It allows users to manage daily tasks by adding, viewing, updating, and removing tasks.

The project demonstrates the use of Python lists, functions, loops, conditional statements, user input handling, and basic error handling.

## 2. Objectives

* Develop a simple To-Do List application using Python.
* Store and manage tasks using Python lists.
* Implement adding, viewing, updating, and deleting operations.
* Practise functions and menu-driven programming.
* Handle invalid user inputs.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Allows users to add new tasks.
* Displays all tasks with numbered entries.
* Allows users to update existing tasks.
* Allows users to remove selected tasks.
* Provides a menu-driven interface.
* Handles invalid menu selections.
* Validates task numbers and empty task descriptions.

## 6. Installation and Setup

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your preferred code editor.
4. Open a terminal in the project directory.
5. Run the program using the command below.

```bash
python "Task 7.py"
```

On some systems, you may need to use `python3` instead of `python`.

## 7. Usage

1. Run the Python program.
2. Select an option from the displayed menu.
3. Enter the task description when adding a task.
4. Select the appropriate task number to update or remove a task.
5. Use the view option to display all available tasks.
6. Select the exit option to close the application.

## 8. Error Handling

The program validates task descriptions and prevents empty task entries. It also handles invalid menu selections, non-numeric task numbers, and task numbers outside the available list range.

Tasks are stored in memory and are not permanently saved after the program exits.

## 9. Learning Outcomes

This project provides practical experience with Python lists, functions, loops, indexing, conditional statements, exception handling, and input validation. It also improves understanding of menu-driven application development.

## 10. Conclusion

The Simple To-Do List project demonstrates how Python can be used to develop a basic task-management application. It provides a foundation for understanding list manipulation, data management, and interactive programming.
