# Word and Character Counter

## 1. Project Overview

The Word and Character Counter is a Python application that accepts a paragraph from the user and calculates basic text statistics. It displays the total number of characters, words, sentences, and spaces.

The project demonstrates string manipulation, regular expressions, loops, and text processing in Python.

## 2. Objectives

* Develop a word and character counting program.
* Calculate the total number of words and characters.
* Identify sentence-ending punctuation.
* Practise string methods and regular expressions.
* Handle multi-line user input.

## 3. Technologies Used

* Python 3
* re module
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Accepts multi-line text input.
* Counts total characters, including spaces and line breaks.
* Counts words using whitespace separation.
* Counts sentences using punctuation marks.
* Counts ordinary spaces.
* Displays the calculated statistics.

## 7. Usage

1. Run the Python program.
2. Type or paste a paragraph.
3. Press Enter on an empty line to finish the input.
4. View the displayed word and character statistics.

## 8. Error Handling

The program handles end-of-file input gracefully. Sentence counting uses punctuation marks followed by whitespace or the end of the text. It provides a basic sentence estimate rather than advanced linguistic sentence detection.

## 9. Learning Outcomes

This project develops practical knowledge of string manipulation, split(), count(), regular expressions, loops, and text processing.

## 10. Conclusion

The Word and Character Counter demonstrates how Python can be used to analyse text and generate useful statistics. It strengthens understanding of string operations and basic text-processing techniques.
