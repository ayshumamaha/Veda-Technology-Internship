# Number Guessing Game Using Python

## 1. Project Overview

The Number Guessing Game is a console-based Python application in which the computer randomly selects a number between 1 and 100. The user attempts to guess the number, receiving hints indicating whether each guess is too high or too low.

The project demonstrates random number generation, loops, conditional statements, user input handling, and basic program logic.

## 2. Objectives

* Develop a number guessing game using Python.
* Generate random numbers using the random module.
* Practise loops and conditional statements.
* Accept and compare user guesses.
* Count the number of attempts required to find the correct number.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Generates a random integer between 1 and 100.
* Accepts guesses from the user.
* Provides hints such as Too High and Too Low.
* Continues until the correct number is guessed.
* Displays the total number of attempts.

## 6. Installation and Setup

1. Install Python 3 on your computer.
2. Download or clone the repository.
3. Open the project folder in your preferred code editor.
4. Open a terminal in the project directory.
5. Run the program.

```bash
python "Task 4.py"
```

## 7. Usage

1. Run the Python program.
2. Enter a whole-number guess between 1 and 100.
3. Follow the hints displayed by the program.
4. Continue guessing until the correct number is found.
5. View the total number of attempts.

## 8. Error Handling

The program expects integer input. Entering non-numeric text may raise a ValueError. Users should enter valid whole-number guesses.

## 9. Learning Outcomes

This project provides practical experience with random number generation, loops, conditional statements, user input, counters, and basic Python programming logic.

## 10. Conclusion

The Number Guessing Game demonstrates how Python can be used to develop an interactive command-line application. It strengthens understanding of randomisation, decision-making, and repetitive program execution.
