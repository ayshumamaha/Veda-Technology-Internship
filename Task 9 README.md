# Student Records Management Using Python Lists

## 1. Project Overview

The Student Records Management program collects student names and marks and stores them using Python lists. It allows users to view student records, search for students, sort records according to marks, and identify the highest and lowest scores.

The project demonstrates list operations, searching, sorting, loops, and basic data processing.

## 2. Objectives

* Practise creating and updating Python lists.
* Store student names and marks.
* Search student records by name.
* Sort student records according to marks.
* Identify the highest and lowest marks.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Accepts multiple student records.
* Stores names and marks in separate lists.
* Searches for a student by name.
* Displays records in descending order of marks.
* Identifies students with the highest and lowest marks.

## 6. Installation and Setup

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder in your code editor.
4. Open the terminal.
5. Run the program.

```bash
python "Task 8.py"
```

## 7. Usage

1. Run the Python program.
2. Enter the number of students.
3. Enter each student's name and marks.
4. View the collected student records.
5. Enter a student name to search for their marks.
6. Review the sorted records and highest and lowest scores.

## 8. Error Handling

The program expects the student count to be an integer and marks to be numeric. It displays an appropriate message when a searched student is not found.

## 9. Learning Outcomes

This project develops practical experience with Python lists, loops, searching, sorting, zip(), max(), min(), and basic data processing.

## 10. Conclusion

The Student Records Management project demonstrates how Python lists can be used to organise and process student information. It provides a foundation for understanding structured data handling and basic record-management applications.
