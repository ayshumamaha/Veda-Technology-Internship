# Simple Password Validator

## 1. Project Overview

The Simple Password Validator is a Python application that checks whether a password satisfies basic password-strength requirements. It evaluates password length and checks for uppercase letters, lowercase letters, digits, and special characters.

The project demonstrates string manipulation, conditional statements, functions, and validation logic in Python.

## 2. Objectives

* Develop a password validation program using Python.
* Check passwords against multiple security requirements.
* Practise string operations and character checking.
* Use conditional statements and functions.
* Display appropriate validation messages.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Checks minimum password length of eight characters.
* Verifies uppercase letters.
* Verifies lowercase letters.
* Checks for at least one numerical digit.
* Checks for special characters.
* Displays validation errors when requirements are not satisfied.


## 7. Usage

1. Run the Python program.
2. Enter a password when prompted.
3. The program checks the password against the defined requirements.
4. Review the validation result and any missing requirements.

## 8. Error Handling

The program identifies unmet password requirements and displays appropriate messages. Password validation is performed locally during execution.

## 9. Learning Outcomes

This project develops practical knowledge of string manipulation, functions, conditional statements, loops, character methods, and input validation.

## 10. Conclusion

The Simple Password Validator demonstrates how Python can be used to implement basic password-strength checking. It provides a foundation for understanding validation logic and developing more secure applications.
