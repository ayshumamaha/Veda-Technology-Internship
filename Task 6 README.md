Simple Password Validator
1. Project Overview
The Simple Password Validator is a console-based Python program that checks whether a password satisfies a set of basic strength requirements. It evaluates the password's length and checks for uppercase letters, lowercase letters, digits, and special characters.
2. Objectives
Practise string operations and character testing.
Validate passwords against multiple rules.
Use loops, conditional statements, and functions.
Display clear validation feedback.
3. Technologies Used
Python 3
Visual Studio Code or another Python-compatible editor
Command Prompt or terminal
Git and GitHub for version control and project submission
4. Features
Requires a minimum password length of eight characters.
Checks for at least one uppercase letter and one lowercase letter.
Checks for at least one digit.
Checks for at least one special character.
Displays all unmet requirements.

6. Installation and Setup
Install Python 3 on your computer.
Download or clone the project repository.
Open the project folder in your preferred code editor.
Open a terminal in the project directory.
Run the program:
```bash
python "Task 6.py"
```
On some systems, you may need to use `python3` instead of `python`.
7. Usage
Run the Python file.
Enter a password when prompted.
Review the validation result and any requirements that were not met.
8. Error Handling
The program reports unmet password rules. It does not store or transmit the password; validation is performed locally during execution.
9. Learning Outcomes
Builds experience with strings, `any()`, character methods, lists, functions, and conditional validation.
10. Conclusion
The Simple Password Validator project demonstrates practical use of Python concepts to solve a focused programming task. It reinforces structured program design, clear user interaction, and the techniques required to build and improve Python applications.
