# Simple To-Do List Using Python

## 1. Project Overview

The Simple To-Do List is a menu-driven Python application that allows users to manage daily tasks. It provides options to add, view, update, and remove tasks using a Python list.

The project demonstrates list operations, functions, loops, conditional statements, and input validation.

## 2. Objectives

* Develop a simple task-management application.
* Store tasks using Python lists.
* Implement adding, viewing, updating, and deleting operations.
* Practise functions and menu-driven programming.
* Validate user inputs.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Adds new tasks to the list.
* Displays tasks with numbered entries.
* Updates existing tasks.
* Removes selected tasks.
* Provides a menu-driven interface.
* Handles invalid menu selections and task numbers.

## 5. Project Structure

```text
simple-todo-list/

```

## 6. Installation and Setup

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder.
4. Open a terminal in the project directory.
5. Run the program.

```bash
python "Task 7.py"
```

## 7. Usage

1. Run the Python program.
2. Select an option from the displayed menu.
3. Enter task details when adding a task.
4. Select the appropriate task number to update or remove a task.
5. View the updated task list.
6. Select Exit to close the application.

## 8. Error Handling

The program checks for empty task descriptions, invalid menu selections, non-numeric task numbers, and task numbers outside the available list range.

Tasks are stored in memory and are not retained after the program exits.

## 9. Learning Outcomes

This project provides practical experience with Python lists, functions, loops, indexing, conditional statements, exception handling, and input validation.

## 10. Conclusion

The Simple To-Do List demonstrates how Python can be used to create a basic task-management application. It strengthens understanding of data storage, list manipulation, and interactive program development.
