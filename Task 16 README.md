# Employee Salary Calculator

## 1. Project Overview

The Employee Salary Calculator is a Python application that calculates employee gross salary, deductions, and net salary using configurable salary rules. It includes allowance calculations, deduction calculations, and sample employee records.

The project demonstrates arithmetic operations, dictionaries, functions, input validation, and structured data processing.

## 2. Objectives

* Develop an employee salary calculation program.
* Calculate gross salary and net salary.
* Understand salary components and deductions.
* Practise functions and dictionary operations.
* Validate employee salary information.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Calculates house rent allowance based on a configured percentage.
* Adds fixed transport and medical allowances.
* Calculates provident fund deductions.
* Calculates professional tax and income tax deductions.
* Displays gross salary.
* Displays individual deductions.
* Calculates final net salary.
* Includes sample employee records for demonstration.

## 7. Usage

1. Run the Python program.
2. Enter the employee details requested by the program.
3. Enter the basic salary.
4. The program calculates allowances and deductions.
5. Review the gross salary and net salary breakdown.

## 8. Error Handling

The program validates numeric salary inputs and rejects negative values. The salary rates and fixed amounts are configurable illustrative rules and should not be treated as official payroll or tax advice.

## 9. Learning Outcomes

This project develops practical experience with functions, dictionaries, percentage calculations, numeric validation, arithmetic operations, and structured output.

## 10. Conclusion

The Employee Salary Calculator demonstrates how Python can be used to automate salary calculations. It provides practical knowledge of financial calculations, input validation, and structured program development.
