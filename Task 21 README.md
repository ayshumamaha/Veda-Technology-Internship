# Date and Time Utility

## 1. Project Overview

The Date and Time Utility is a menu-driven Python application that performs different date and time operations. It calculates age, finds the number of days between two dates, counts weekdays, and displays the current date and time in different formats.

The project demonstrates the use of Python's datetime module, date parsing, date arithmetic, functions, and exception handling.

## 2. Objectives

* Develop a date and time utility using Python.
* Understand the datetime module.
* Calculate age from a date of birth.
* Find the difference between two dates.
* Count weekdays within a date range.
* Practise date formatting and validation.

## 3. Technologies Used

* Python 3
* datetime module
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Calculates age in completed years.
* Calculates the number of days between two dates.
* Counts weekdays between selected dates.
* Displays the current date.
* Displays the current time.
* Shows the current weekday.
* Formats dates into readable formats.
* Includes sample date calculations.

## 7. Usage

1. Run the Python program.
2. Select an option from the Date and Time Utility menu.
3. Enter dates in YYYY-MM-DD format when requested.
4. Review the calculated age or date difference.
5. View weekday counts or current date and time information.
6. Select the exit option to close the program.

## 8. Error Handling

The program validates date input and prompts the user again when an invalid date is entered. Future birth dates are rejected. The weekday calculation counts Monday through Friday and does not account for public holidays.

## 9. Learning Outcomes

This project provides practical experience with the datetime module, date parsing, date arithmetic, timedelta, functions, loops, exception handling, and date formatting.

## 10. Conclusion

The Date and Time Utility demonstrates how Python can be used to perform useful date-related calculations. It strengthens understanding of date processing, validation, and practical programming applications.
