# Simple Calculator Using Python

## 1. Project Overview

The Simple Calculator is a console-based Python application developed as part of the Python Programming Internship at Veda Technology. It accepts two numerical inputs from the user and performs basic arithmetic operations, including addition, subtraction, multiplication, division, and modulus.

The project demonstrates the use of arithmetic operators, user input handling, conditional statements, functions, and basic error handling in Python.

## 2. Objectives

* Develop a simple calculator using Python.
* Perform addition, subtraction, multiplication, division, and modulus operations.
* Practise arithmetic operators and basic program logic.
* Handle division by zero safely.
* Display calculation results clearly.

## 3. Technologies Used

* Python 3
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Accepts two numerical inputs.
* Supports five arithmetic operations.
* Uses a menu-driven interface.
* Handles invalid operation selections.
* Prevents division-by-zero errors.
* Displays the result of the selected operation.

## 6. Installation and Setup

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your preferred code editor.
4. Open a terminal in the project directory.
5. Run the program using the command below.

```bash
python calculator.py
```

On some systems, you may need to use `python3 calculator.py` instead.

## 7. Usage

1. Run the Python program.
2. Enter the first number when prompted.
3. Enter the second number.
4. Select an arithmetic operation from the displayed menu.
5. View the calculation result.
6. Follow the program prompts to continue or exit.

## 8. Error Handling

The program validates numerical inputs and handles invalid operation selections. It also checks the second operand before performing division or modulus so that division-by-zero errors are avoided.

## 9. Learning Outcomes

This project provides practical experience with Python arithmetic operators, functions, conditional statements, user input, exception handling, and program execution. It also reinforces the importance of validating input and handling errors when developing simple applications.

## 10. Conclusion

The Simple Calculator project demonstrates how Python can be used to build a useful command-line application. It provides a foundation for understanding arithmetic operations, input validation, and basic programming logic, supporting further learning in Python application development.
