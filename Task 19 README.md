# Read and Process a Text File

## 1. Project Overview

The Read and Process a Text File application is a Python program that reads a text file and calculates the total number of lines, words, and characters. It accepts a file path from the user and processes the contents line by line.

The project demonstrates file handling, text processing, loops, and exception handling in Python.

## 2. Objectives

* Develop a text-file reading application.
* Understand Python file-handling operations.
* Count lines, words, and characters.
* Practise reading files line by line.
* Handle missing files and file-access errors.

## 3. Technologies Used

* Python 3
* pathlib module
* Visual Studio Code or another Python-compatible editor
* Command Prompt or terminal
* Git and GitHub for version control and project submission

## 4. Features

* Accepts a text-file path from the user.
* Reads files using UTF-8 encoding.
* Counts the total number of lines.
* Counts the total number of words.
* Counts the total number of characters.
* Processes file contents line by line.
* Displays the calculated statistics.

## 6. Installation and Setup

1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder in your code editor.
4. Place a text file in the project directory or note its full path.
5. Open the terminal.
6. Run the program.

```bash
python "Task 17.py"
```

## 7. Usage

1. Run the Python program.
2. Enter the path of the text file.
3. The program reads the file contents.
4. View the total number of lines, words, and characters.
5. Check the displayed output.

## 8. Error Handling

The program handles FileNotFoundError when the specified file does not exist. It also handles OSError for other file-access problems and displays appropriate error messages.

## 9. Learning Outcomes

This project provides practical experience with file handling, pathlib, context managers, loops, string processing, file reading, and exception handling.

## 10. Conclusion

The Read and Process a Text File project demonstrates how Python can be used to read and analyse text files. It strengthens understanding of file operations and basic data-processing techniques.
