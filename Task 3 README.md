Student Grade Calculator
About the Project
The Student Grade Calculator is a simple Python project developed as part of VEDA Technology Internship – Task 4. It calculates a student's total marks, percentage, and grade based on marks entered for multiple subjects.

Features
Accepts student name and number of subjects.
Takes marks for each subject.
Validates marks between 0 and 100.
Calculates total marks and percentage.
Assigns grades based on predefined conditions.
Displays PASS or FAIL.
Handles invalid numeric input.
Technologies Used
Python 3
Grade Criteria
Percentage	Grade
90–100%	A+
80–89.99%	A
70–79.99%	B
60–69.99%	C
50–59.99%	D
Below 50%	F

Passing Criteria: 50% or above.

How to Run
Install Python 3.
Save the code as grade_calculator.py.
Open a terminal in the project folder.
Run the following command:
python grade_calculator.py


If your system uses Python 3 through python3, run: python3 grade_calculator.py

Enter the student name, number of subjects, and marks when prompted.
